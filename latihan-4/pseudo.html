link

style default pada sebauh link (a yang memiliki href)

hover

style ketika kursor mouse berda diatas link

active

style ketika sebuah link di-klik

visited

style ketika sebuah link sudah pernah di kunjungi sebelumnya

first-child

memilih elemen pertama dari sebuah parent(elemen pebungkus nya)

last-child

memilih elemen terakhir dari sebuah parent (elemen pembungkus nya)

nth-child

memilih elemen ke-n dari sebuah parent(elemen pembungkus nya)
n bisa berarti urutan 1,2,.. atau pola 2n, 3n+2n, 4n+1n atau ganjil genap (even)&odd

first-of-type

memilih elemen pertama dari sebuah jenis/tipe tag

last-of-type

memilih elemen terakhir dari sebuah jenis / tipe tag
